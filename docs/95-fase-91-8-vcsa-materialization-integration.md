# Fase 91.8 — VCSA Materialization & Provenance Integration

VCSA estruturalmente válido possui um protótipo runtime único:
`MaterializedEvidence`. O `EvidenceItem.text_snapshot` permanece imutável e
citável; o protótipo preserva parent, target, hashes, regra e texto efetivo.
Ele não foi conectado aos consumidores de produção nesta fase.

Para prisão perpétua, a projeção literal é `não haverá penas: de caráter
perpétuo;`. A identidade jurídica citável permanece a alínea B, não uma
identidade VCSA artificial.

Os controles focais passaram, incluindo imutabilidade, determinismo, negação
no Polarity Guard e compatibilidade legacy. Contudo, a suíte completa dentro do
container não pôde ser executada porque a reconstrução da imagem foi bloqueada
pelo filesystem do builder, e o replay histórico completo de EvidenceSets não
foi realizado. A integração de produção permanece `INCONCLUSIVE`; nenhum E2E
ou LLM foi executado.
