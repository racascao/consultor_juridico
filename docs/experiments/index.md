# Experimentos do MVP2

Esta seção responde: **como descobrimos que a arquitetura final era adequada?**
Ela preserva hipóteses, medições, decisões e condições de reconsideração, sem
transformar tentativas históricas no caminho pedagógico principal.

## Método

```text
Problema → hipótese geral → experimento controlado → resultado
         → decisão → condição para reconsiderar
```

Uma medição não pode mudar silenciosamente dataset, prompt, modelo ou threshold.
Scores automáticos avaliam contratos; revisão humana avalia a substância jurídica.

## Lições herdadas do MVP1

- medir componentes isolados antes de ampliar a arquitetura;
- separar retrieval de capacidade do answerer;
- exigir evidência, proveniência e citação válida;
- congelar contratos antes da avaliação final;
- preferir abstenção a conteúdo não sustentado.

O MVP1 aparece aqui apenas como origem dessas lições; seu código permanece na
tag imutável `v0.1.0`.
